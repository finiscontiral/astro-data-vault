# AstroDataVault (日本語ドキュメント)

[English](../README.md) | **日本語**

TLEやCCSDS規格（OMM/OPM/OEM等）の軌道要素データを一元管理・検索するデスクトップアプリ＆ライブラリ

## 特徴

- **複数フォーマットの自動パース・格納**
    - TLEだけでなく、CCSDSの規格の OMM, OPM, OEMに対応予定
- **データの再エクスポート機能**
    - 保存された軌道データの書き出しに対応予定
